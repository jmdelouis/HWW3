# API and scripts

## Rust crate `hww3_grid`

The full API reference is generated by `rustdoc` and published with this
site: <a href="rust/hww3_grid/index.html">Rust API reference</a>. Every public item is
documented (`#![warn(missing_docs)]`; the CI builds the documentation with
warnings as errors).

| Module | Role |
|---|---|
| `config` | JSON configuration (`Config`, `Quality`, `Ww3Params`) |
| `pipeline` | `build` (all steps) and `write` (output files), `Summary`, `Grid` |
| `coast`, `shapefile`, `gshhg` | coastline readers and nearest-point index |
| `refine` | OceanMesh2D size functions from the bathymetry (`wl`, `slp`, `fl`, grade), cells to split |
| `tree` | refinement and 2:1 balance |
| `bathy` | bathymetry grid and cell statistics |
| `mesh` | triangulation, ear clipping, pinch removal, Delaunay flips, boundary trimming |
| `validate` | mesh checks (`MeshReport`) |
| `ww3` | Gmsh, open-boundary, namelist and raw writers |
| `geo` | ellipsoid (authalic latitude) and vector helpers |

## Rust crate `hww3_wave`

The GPU wave model ([GPU wave model](wave_model.md)). Its API reference is
published with this site:
<a href="rust-wave/hww3_wave/index.html">Rust API reference of hww3-wave</a>,
built with both backends. As for `hww3_grid`, every public item is
documented and the CI builds the documentation with warnings as errors.

| Module | GPU | Role |
|---|---|---|
| `grid` | no | HWW3 grid reader (`Grid`, `Spectrum`), lon/lat box cut |
| `geom` | no | `Geometry`: normals, `PDLIB_SI`, boundary flags, velocities, `ITER` |
| `spec` | no | `Spec` (spectral grid of `W3GRID`), `wavnu3`, `node_wavenumbers` |
| `ww3io` | no | `Restart` (`read`, `write`, `calm`), `FieldFile`, `FieldWriter`, `NestFile`, `NestWriter`, `SeqFile`, `Time` |
| `reference` | no | `step`: `PDLIB_W3XYPFSN2` on the CPU in double precision |
| `cpu` | no | `ktp3` (`W3KTP3`) and `geo_freq` (`PDLIB_W3XYPUG`) on the CPU |
| `harness` | no | readers of the WW3 source-term harness files and of their parameter files (`Harness`, `Params`) |
| `ww3grid` | no | `source_params`: the parameter file of the source terms from the namelists and the grid (`ww3_grid`); `Namelists`, `GridSetup` |
| `prnc` | no | `SourceGrid::weights`, `Weights::interp`, `Field::process`, `unpack`, `RawInput`: the interpolation of `ww3_prnc` |
| `bounc` | no | `dist_haversine`, `station_weights`, `RawSpectra`, `boundary_nodes`: `ww3_bounc` |
| `sources` | no | the ST4 source terms, DIA, LN1, DB1, BT4 and `W3SRCE` on the CPU in double precision; `SrceTables` (their layout for the GPU), `tabu_tauhf2` (the tail-stress tables and their derivative with respect to `BETAMAX`), `BetaU` and `betau_tables` (`BETAMAX`$(U)$: knots, coefficients and the tail-stress tables at a grid of `BETAMAX`) |
| `backend` | no | `Sweeper` (forward and transposed sub-steps), `Scalar`, `Dims` |
| `kernels` | CubeCL | N-scheme kernels: `fused`, `two_phase`, `two_phase_x4`, forward and transpose |
| `device` | CubeCL | `DeviceGrid`: the CubeCL `Sweeper` |
| `burn_ext` | CubeCL | `substep`: a sub-step on Burn's autodiff tape |
| `prop` | CubeCL | kernels of the propagation-only model |
| `srce` | CubeCL | `srce`: the whole `W3SRCE` integration, one cube per node; `wind_interp` (`W3UWND`); `SourceKernel` |
| `srce_tl` | CubeCL | `srce_tl`: `srce` with its tangent (M3), `TangentArgs`, `SourceKernel::launch_tl` |
| `prop_tl` | CubeCL | tangents of `W3KTP3`, of the geographic node update, of the level remap, of the wind and of the outputs (M3) |
| `model` | CubeCL | `Model`, `Config`, `Inputs`: the time loop, with the source terms and, with `Config::tangent`, the tangent |
| `cuda_c` | CUDA C | `CudaGrid`: the `cudarc` `Sweeper` |

Programs: `hww3-wave` (M0 timings and checks), `hww3-prop` (the model;
`--tangent` for the M3 tangent) and `hww3-src` (the source terms against
the WW3 harness; `check-tl` for the M3 tangent kernel; `tables` and
`params` for the stress tables computed in Rust and the parameter file of
other values of the calibrated parameters). The Fortran harness
`harness/src_harness.F90` is built against the WW3 library.

## Scripts (`scripts/`)

| Script | Role |
|---|---|
| `fetch_sources.sh` | download WW3, netCDF-Fortran, ParMETIS, GEBCO |
| `prep_gebco.py` | cut GEBCO to the domain (raw f32 + `meta.json`) |
| `natl_grid.pbs` / `.slurm` | build the North Atlantic grid (Datarmor / hpc) |
| `natl_extract.sh`, `extract_zoom.py` | plotting subsets of a grid |
| `plot_levels.py`, `plot_cells_tris.py`, `plot_mesh.py` | grid figures |
| `build_ww3.pbs` / `build_ww3_hpc.slurm` | build WW3 and its dependencies (Datarmor / hpc) |
| `natl_ww3_grid.pbs` | run `ww3_grid` |
| `natl_test.pbs`, `plot_hs.py` | homogeneous-wind test and $H_s$ map |
| `get_era5.py`, `prep_era5.py` | ERA5 download and `ww3_prnc` input |
| `prep_cmems.py` | Copernicus Marine currents and sea level from the Datarmor mirror |
| `fes_tides.py`, `natl_tide_setup.pbs` | FES2014 tide added to the Copernicus Marine currents and sea level, and the run directory with the tide |
| `natl_jan2026_*.pbs` | forcing preparation and January 2026 runs |
| `natl_v2_setup.pbs`, `natl_bnd_setup.pbs`, `natl_exp_setup.pbs`, `natl_v2_run.pbs` | run setups (implicit, open-boundary spectra, explicit scheme) and runs on grids v2 and later |
| `validate_altimetry.py`, `validate_buoys.py`, `natl_validate.pbs`, `natl_buoys.pbs` | $H_s$ against L3 altimetry, $H_s$ and $T_{m02}$ against moored buoys |
| `explicit_cost.py`, `natl_explicit_cost.pbs`, `plot_explicit_cost.py` | sub-cycling of the explicit scheme per node and component |
| `plot_run_diff.py`, `plot_level_change.py` | differences between two runs (same or different grids) and between two grids |
| `ww3_loc.py`, `subdomain.py` | Fortran lines of the routines to port; Channel–Biscay test box cut from a grid |
| `wave_m0_hpc.slurm` / `wave_m0.pbs` | GPU model, milestone M0: sweep times and dot-product tests (CubeCL on hpc / CUDA C on Datarmor) |
| `m1_ww3_prop_hpc.slurm`, `natl_prop_run.pbs` | propagation-only WW3 references (hpc / Datarmor) |
| `m1_prop_hpc.slurm` | GPU model, milestone M1: propagation-only runs and checks |
| `m1_compare_nc.py`, `m1_compare.py` | hourly $H_s$ and $T_{m02}$ (or `--vars`, such as the wind) of the GPU model against a WW3 run (without numpy / with numpy) |
| `gpu_to_nc.py` | the hourly fields of the GPU model as a netCDF file shaped like the WW3 output, for the validation scripts |
| `m2_scores_hpc.slurm` | altimeter and buoy scores of a WW3 run and of the GPU run on the hpc cluster (`gpu_to_nc.py`, `validate_altimetry.py`, `validate_buoys.py`) |
| `m2_ww3_ref_hpc.slurm` | WW3 references of M2a with the simplified ST4 (`SINTABLE = 0`, `SDSCUM = 0`): 48 h from a restart or the cold-started week |
| `m2_ww3_bccfl_hpc.slurm` | the explicit WW3 run with sources twice on the same node, with `UGBCCFL = T` and `F` (sub-cycling over every wet node or the interior nodes only) |
| `m2_src_harness_hpc.slurm` | builds the source-term harness against the hpc WW3 library and runs it on a restart |
| `m2_src_gpu_hpc.slurm` | the GPU source kernel on the harness nodes against WW3 and the CPU transcription (`hww3-src check-gpu`), single and double precision, and its timing |
| `m2_prop_hpc.slurm` | `hww3-prop` with the source terms on one A100: `check-steps` against the WW3 restarts of the M2a reference, or hourly $H_s$ and $T_{m02}$ |
| `m2_moddef_hpc.slurm` | the calibrated `mod_def.ww3` with another `BETAMAX` (its stress tables), for the finite differences |
| `m2_fd_gradients.py`, `m2_fd_hpc.slurm` | finite-difference gradients of the energy, mean $H_s$ and scores of 48 h GPU runs with respect to `BETAMAX`, `SDSC2`, `NLPROP`, `BJGAM` and the wind |
| `m3_tl_src_hpc.slurm` | the tangent kernel of the source terms against finite differences on the harness nodes (`hww3-src check-tl`) |
| `m3_tl_run_hpc.slurm`, `m3_tl_compare.py` | a tangent run of `hww3-prop` and, with one or two steps, the perturbed runs and the comparison of the tangent with their central differences (with two steps, on the nodes where they agree) |
| `m3_tl_cmp_hpc.slurm` | the 48 h tangent runs against the finite-difference runs of M2b |
| `cal_run_hpc.slurm` | a run of the calibration: value or tangent run with given `BETAMAX` (Rust stress tables), `SDSC2`, `NLPROP`, `BJGAM`, and `BETAMAX`$(U)$ (`BETAU`, `BETAU_GRID`) |
| `cal_obs.py`, `cal_py_hpc.slurm` | the observation operators of the calibration (altimeter blocks, buoy hours, as the validation scripts match them), the cost and its gradient from tangent runs |
| `cal_gn.py` | one Gauss–Newton (Levenberg–Marquardt) step with the posterior covariance; `--smooth` adds the second differences of the `BETAMAX`$(U)$ coefficients to the prior |
| `betau_check_hpc.slurm`, `betau_check.py` | checks of `BETAMAX`$(U)$: all coefficients 0 against the constant `BETAMAX`, its tangents against the `BETAMAX` tangent, the interpolation in `BETAMAX`, a tangent off the grid against central differences |
| `betau_report.py` | report of the `BETAMAX`$(U)$ test: the curve with its posterior uncertainty, and the bias and RMSE of the buoy and altimeter $H_s$ by observed $H_s$ and by wind speed for several runs, through the operators of the third cost |
| `tl_diag.py` | where a tangent run grows: hourly largest tangent of $H_s$ and its node, the nodes where it first exceeds 100 times the 99.99th percentile, and with an operator the altimeter blocks and buoy hours whose derivative is not finite or above a bound |
| `prnc_nc.py` | a netCDF forcing file read as `ww3_prnc` reads it, for `hww3-pre prnc` |
| `bounc_nc.py` | the station spectrum files read as `ww3_bounc` reads them, for `hww3-pre bounc` |
| `pre_inputs_hpc.slurm` | the forcing and boundary files built in Rust from the netCDF inputs of the January runs, compared with those of `ww3_prnc` and `ww3_bounc` |
| `pre_allrust_hpc.slurm`, `pre_allrust_cmp_hpc.slurm` | a GPU run whose inputs all come from Rust (calm start, `build-params`, `hww3-pre`), and its comparison with the calibration's start run |
| `pre_hs_cmp.py` | hourly $H_s$ of two `hww3-prop` runs compared node by node |
| `coast_diag.py` | the buoy $H_s$ bias and RMSE of two runs by depth mismatch, node depth, distance to the coast, HEALPix level and sub-grid descriptors, and a depth-aware matching as a diagnostic |
| `coast_subgrid.py` | the spread of the GEBCO depth and the fraction of land inside the cells of given nodes (run where GEBCO is, with numpy only) |
| `buoy_op.py`, `buoy_op_hpc.slurm` | the depth-aware buoy operator of the calibration (weights from the mesh and a depth kernel, $T_{m02}$ through the moments), its degenerate check and its scores |
| `buoy_depth.py` | the GEBCO depth at the buoys (run where GEBCO is, with numpy only) |
| `obs_diag.py`, `obs_diag_hpc.slurm` | observation diagnostics of the calibration: per-buoy tables and figures, altimeter residuals and noise, Huber and L1 steps against the L2 step |
| `cal_point.py`, `cal_monitor_hpc.slurm` | one point of the calibration under the three costs on both windows: $J$ and its parts, the prior, the unweighted scores |
| `buoy_exclude.py` | candidates for the list of buoys the mesh cannot represent (median observed / model $H_s$), the list itself being `configs/buoy_exclude.csv` |
| `cal_cost3_hpc.slurm` | the third cost (excluded buoys, representativeness errors fitted again, Huber loss) and the start run and step 3 under the four costs |
| `buoy_sigma.py`, `cal_cost2_hpc.slurm` | the representativeness errors of the buoys per class, fixed from the start run, and the stored points of the calibration under the first and the second cost |
| `pre_restart_hpc.slurm` | the start from calm conditions against WW3, and a run continued from a GPU restart against the same run in one piece |
| `cal_fdcheck.py` | the tangent derivatives of the cost and scores against the M2b finite differences (control only) |
