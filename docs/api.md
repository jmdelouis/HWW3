# API and scripts

## Rust crate `hww3_grid`

The full API reference is generated by `rustdoc` and published with this
site: <a href="rust/hww3_grid/index.html">Rust API reference</a>. Every public item is
documented (`#![warn(missing_docs)]`; the CI builds the documentation with
warnings as errors).

| Module | Role |
|---|---|
| `config` | JSON configuration (`Config`, `Quality`, `Ww3Params`) |
| `pipeline` | `build` (all steps) and `write` (output files), `Summary`, `Grid` |
| `coast`, `shapefile`, `gshhg` | coastline readers and nearest-point index |
| `tree` | refinement and 2:1 balance |
| `bathy` | bathymetry grid and cell statistics |
| `mesh` | triangulation, ear clipping, pinch removal, Delaunay flips, boundary trimming |
| `validate` | mesh checks (`MeshReport`) |
| `ww3` | Gmsh, open-boundary, namelist and raw writers |
| `geo` | ellipsoid (authalic latitude) and vector helpers |

## Scripts (`scripts/`)

| Script | Role |
|---|---|
| `fetch_sources.sh` | download WW3, netCDF-Fortran, ParMETIS, GEBCO |
| `prep_gebco.py` | cut GEBCO to the domain (raw f32 + `meta.json`) |
| `natl_grid.pbs` / `.slurm` | build the North Atlantic grid (Datarmor / hpc) |
| `natl_extract.sh`, `extract_zoom.py` | plotting subsets of a grid |
| `plot_levels.py`, `plot_cells_tris.py`, `plot_mesh.py` | grid figures |
| `build_ww3.pbs` | build WW3 and its dependencies |
| `natl_ww3_grid.pbs` | run `ww3_grid` |
| `natl_test.pbs`, `plot_hs.py` | homogeneous-wind test and $H_s$ map |
| `get_era5.py`, `prep_era5.py` | ERA5 download and `ww3_prnc` input |
| `prep_cmems.py` | Copernicus Marine currents and sea level from the Datarmor mirror |
| `natl_jan2026_*.pbs` | forcing preparation and January 2026 runs |
